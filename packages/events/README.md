# @shopong/events

The one OCN event envelope, its canonical JSON (`ocn-jcs-1`, an RFC 8785 profile), the SHA-512 event id and keyed commitments for personal data. Pure TypeScript with no runtime dependencies: it runs on Hermes, browsers, Node and Bare. Hashing and HMAC are injected.

The normative rules are in [ADR 0001](../../docs/adr/0001-event-envelope-and-event-id.md).

```ts
import { createEvent, decodeEvent, encodeEvent, eventIdOf, webCryptoSha512 } from "@shopong/events";

const event = createEvent({
  type: "order.proposed",
  space,
  actor,
  proof,
  claimedAt,
  nonce,
  payload,
});
const id = await eventIdOf(event, webCryptoSha512); // 128 lowercase hex characters
const bytes = encodeEvent(event); // canonical UTF-8: what goes on the wire

const result = decodeEvent(bytes);
if (result.ok && result.known) {
  // apply it
} else if (result.ok) {
  // opaque (unknown type or future version): keep as is, ignore
}
```

## Golden vectors

`vectors/golden.json` is generated by an independent Python implementation:

```sh
pnpm --filter @shopong/events run vectors   # python3 -I scripts/gen_vectors.py vectors/golden.json
```

Edit the inputs in `scripts/gen_vectors.py`, never the JSON. Other platforms (Hermes, the OCN Node, the console) should run the same file. The package exports it as `@shopong/events/vectors/golden.json`.
